Υποστηρίζει κονσόλα (Μέρος 1) και γραφική διεπαφή JavaFX (Μέρος 2), καθώς και
εκτίμηση **VO2 Max** (Προαιρετικό μέρος 2).

## Χρήση – Κονσόλα (Μέρος 1)

### Βασική χρήση

```bash
java -jar target/coach.jar activity.tcx
```

### Πολλαπλά αρχεία

```bash
java -jar target/coach.jar run1.tcx run2.tcx run3.tcx
```

### Με βάρος (ενεργοποιεί υπολογισμό θερμίδων)

```bash
java -jar target/coach.jar -w 70.5 run1.tcx
```

### Πλήρης χρήση με όλες τις παραμέτρους

```bash
java -jar target/coach.jar \
  -w 70.5   \   # βάρος σε kg
  -a 28     \   # ηλικία
  -g male   \   # φύλο (male/female)
  -r 62     \   # παλμοί ηρεμίας (για VO2 Max)
  -c 2      \   # μέθοδος θερμίδων: 1=Απλή, 2=HR, 3=VO2Max
  run.tcx
```

## Αρχιτεκτονική

Η εφαρμογή χρησιμοποιεί **ιεραρχική δομή δεδομένων**:

```
Activity
  └── Lap[]
        └── Track[]
              └── Trackpoint[]
                    ├── timestamp
                    ├── latitude, longitude
                    ├── altitudeMeters
                    ├── distanceMeters  (αθροιστική)
                    ├── heartRateBpm
                    └── cadence
```

Τα στατιστικά υπολογίζονται **ιεραρχικά** — κάθε επίπεδο αθροίζει τα παιδιά του.

### Σχέδια (Design Patterns)

- **Strategy**: `CalorieCalculator` interface — εύκολη εναλλαγή μεθόδου υπολογισμού
- **Template Method**: `Activity` abstract class — κοινή λογική, εξειδίκευση στις υποκλάσεις
- **Factory (λογική)**: `TcxParser.createActivity()` — επιλογή σωστής υποκλάσης

## Υπολογισμός Θερμίδων

Η εφαρμογή υποστηρίζει τρεις μεθόδους (επιλέγονται με `-c` στην κονσόλα ή από το GUI):

### Μέθοδος 1: Απλή (MET)
```
C = μ · w · t
```
- `μ` = πολλαπλασιαστής ανά άθλημα (Running: 0.0175, Biking: 0.0133, κ.α.)
- `w` = βάρος σε kg
- `t` = χρόνος σε λεπτά

### Μέθοδος 2: Καρδιακοί παλμοί (Keytel et al., 2005)

**Άνδρες:**
```
C = (-55.0969 + 0.6309·h + 0.1966·w + 0.2017·a) · t / 4.184
```
**Γυναίκες:**
```
C = (-20.4022 + 0.4472·h + 0.1263·w + 0.074·a) · t / 4.184
```
- `h` = μέσοι καρδιακοί παλμοί (bpm)
- `a` = ηλικία (χρόνια)

### Μέθοδος 3: VO2 Max
```
C = VO2Max · w · t / 200
```
*(βλέπε παρακάτω για τον υπολογισμό VO2 Max)*

## VO2 Max (Προαιρετικό Μέρος 2)

### Υπολογισμός (Uth et al., 2004)

```
MHR     = 220 − ηλικία
VO2Max  = 15.3 × (MHR / RHR)
```

Όπου `RHR` = παλμοί ηρεμίας (Resting Heart Rate).

### Πίνακας αξιολόγησης (άνδρες, ml/kg/min)

| Ηλικία | Άριστο | Καλό  | Πάνω από Μέσο | Μέσο  | Κάτω  |
|--------|--------|-------|---------------|-------|-------|
| 20–29  | ≥52.4  | ≥46.4 | ≥42.4         | ≥37.1 | ≥33.0 |
| 30–39  | ≥49.4  | ≥43.4 | ≥39.2         | ≥35.4 | ≥31.1 |
| 40–49  | ≥48.0  | ≥43.7 | ≥38.4         | ≥33.6 | ≥30.2 |

## Δομή Κώδικα

```
src/main/java/
│
├── Main.java                        ← Σημείο εισόδου (κονσόλα + GUI)
│
├── model/
│   ├── Trackpoint.java              ← Σημείο GPS (timestamp, HR, κτλ.)
│   ├── Track.java                   ← Λίστα Trackpoints
│   ├── Lap.java                     ← Γύρος (περιέχει Tracks)
│   ├── Activity.java                
│   ├── RunningActivity.java         ← Τρέξιμο
│   ├── CyclingActivity.java         ← Ποδήλατο
│   ├── WalkingActivity.java         ← Περπάτημα
│   ├── SwimmingActivity.java        ← Κολύμπι
│   └── UserProfile.java             ← Δεδομένα χρήστη (ηλικία, βάρος κτλ.)
│
├── parser/
│   └── TcxParser.java               ← Ανάλυση XML αρχείων TCX
│
├── stats/
│   └── ActivityStats.java           ← Υπολογισμός & μορφοποίηση στατιστικών
│
├── calories/
│   ├── CalorieCalculator.java       ← Strategy interface
│   ├── SimpleCalorieCalculator.java ← Μέθοδος 1: MET
│   ├── HRCalorieCalculator.java     ← Μέθοδος 2: Καρδιακοί παλμοί
│   └── VO2MaxCalorieCalculator.java ← Μέθοδος 3: VO2 Max
│
├── vo2max/
│   └── VO2MaxEstimator.java         ← Εκτίμηση VO2 Max + αξιολόγηση (Προαιρετικό 2)
│
└── gui/
    └── FitnessApp.java              ← JavaFX εφαρμογή (Μέρος 2)
```
